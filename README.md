# Camper Café Menu

![Cafe Menu Preview](https://cdn.freecodecamp.org/curriculum/css-cafe/beans.jpg)

A beautiful, responsive café menu built with **HTML and CSS**.

## ✨ Features

- Fully responsive design (works great on mobile and desktop)
- Clean and elegant café styling
- Background image with overlay content
- Well-organized Coffee and Desserts sections
- Hover effects and proper typography

## 🛠️ Technologies Used

- HTML5
- CSS3
